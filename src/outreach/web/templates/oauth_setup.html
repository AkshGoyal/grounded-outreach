Administrator setup

Choose an HTTPS host for the real Python app. Set its address as OUTREACH_OAUTH_PUBLIC_URL, add its hostname to OUTREACH_ALLOWED_HOSTS, and protect it with OUTREACH_APP_PASSWORD.

Google: create a Web application OAuth client, enable Gmail API, configure the consent screen and test users. Set OUTREACH_GOOGLE_CLIENT_ID and OUTREACH_GOOGLE_CLIENT_SECRET. Register callback {{ public_url or 'https://YOUR-APP' }}/accounts/oauth/gmail/callback.

Zoho: create a Server-based application in the API Console for your account region. Set OUTREACH_ZOHO_CLIENT_ID and OUTREACH_ZOHO_CLIENT_SECRET. Register callback {{ public_url or 'https://YOUR-APP' }}/accounts/oauth/zoho/callback.
